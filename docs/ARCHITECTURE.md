# PRESTİJ — architecture and contracts

Read this before writing code. `docs/NEXT16-NOTES.md` is the authority for Next.js 16.4 APIs
(caching, revalidation, proxy, params). When the two disagree about a Next.js API, NEXT16-NOTES wins.

## Product goal
Luxury-minimal e-commerce for PRESTİJ (liquid hand soap, shower gel; Kayseri, Türkiye).
Storefront must feel premium and be extremely fast. **Everything visible on the storefront is data
edited in the admin panel** (texts, colors, sections, menus, prices, legal texts). No hard-coded copy
except the default UI dictionary, which the panel can override.

Audience: home customers AND businesses (hotels, spas, offices, restaurants). B2B = company accounts,
group prices, volume tiers, quote requests, free sample requests, invoice with tax number.

## Stack
Next.js 16.4 (App Router, `cacheComponents: true`, Turbopack) · React 19.3 · TypeScript strict ·
Tailwind CSS 4 · Drizzle ORM 0.45 + postgres.js · PostgreSQL 17 (local: `npm run db`; prod: Supabase) ·
Better Auth 1.7 · zod 4 · culori (color math) · motion (animation) · sharp (image pipeline) · lucide-react.

Commands: `npm run dev` (starts DB + Next) · `npm run db:generate` / `db:migrate` · `npm run db:seed` ·
`npm run typecheck` · `npm run lint` · `npm run build`.
Database: drizzle with `casing: "snake_case"` — TypeScript keys are camelCase, columns snake_case.
Schema: `src/db/schema/*.ts`. Import the client with `import { db, schema } from "@/db"` (server only).
Never change the schema without running `npm run db:generate` and `npm run db:migrate`.

## Core contracts (implement exactly these names)

### i18n — `src/i18n`
- `config.ts`: `locales = ["tr","en","ar"] as const`, `defaultLocale = "tr"`, `rtlLocales = ["ar"]`,
  `isLocale(x): x is Locale`, `localeDir(l): "ltr"|"rtl"`, `localeNames` (Türkçe / English / العربية),
  `intlLocale(l)` → `"tr-TR" | "en-US" | "ar-u-nu-latn"` (Arabic text, Latin digits).
- `localize(text: LocalizedText | null | undefined, locale): string` — falls back to `tr`, then "".
- `messages/tr.ts` exports the default UI dictionary (nested object, `as const` not required);
  `en.ts` / `ar.ts` export the same shape (`satisfies Messages`). Keys are grouped: `common`, `header`,
  `footer`, `product`, `cart`, `checkout`, `account`, `b2b`, `sample`, `newsletter`, `errors`.
- `getMessages(locale): Promise<Messages>` — cached (`"use cache"`, tag `TAGS.uiStrings`), deep-merges
  DB overrides from `ui_strings` (flat dotted keys like `header.cart`).
- Localized URL segments. Folders are Turkish (canonical); en/ar URLs use English segments and
  `proxy.ts` rewrites them: `urunler↔products`, `kategori↔category`, `sepet↔cart`, `odeme↔checkout`,
  `hesap↔account`, `kurumsal↔business`, `numune↔samples`, `blog↔blog`, `sayfa↔page`, `iletisim↔contact`.
  `paths.ts` exports `href(locale, route, params?)` that builds the public URL (e.g.
  `href("en","product",{slug:"lavanta"})` → `/en/products/lavanta`). Always build links with `href`.

### Cache tags — `src/lib/cache-tags.ts`
```ts
export const TAGS = {
  settings: "settings", theme: "theme", menus: "menus", announcements: "announcements",
  uiStrings: "ui-strings", pages: "pages", page: (slug: string) => `page:${slug}`,
  products: "products", product: (slug: string) => `product:${slug}`, categories: "categories",
  reviews: (productId: number) => `reviews:${productId}`, blog: "blog", post: (slug: string) => `post:${slug}`,
  legal: "legal", media: "media",
} as const;
```
Storefront reads are `"use cache"` functions tagged with these. Panel mutations invalidate the matching
tags (see NEXT16-NOTES for `updateTag` vs `revalidateTag`). Anything time-dependent (scheduled themes,
announcements, campaigns) also sets a short `cacheLife` so schedules switch on time.

### Settings — `src/lib/settings`
`types.ts` defines a zod schema + defaults per key: `general` (siteName, legalName, phone, email,
whatsapp, address, social, logo media ids), `shipping` (flatFee, freeThreshold, heavy surcharge:
thresholdGrams + feePerKg, carriers), `payments` (card: enabled + provider iyzico|paytr + testMode;
bankTransfer: enabled + accounts[{bank, holder, iban}] + discountPercent; cashOnDelivery: enabled + fee),
`seo`, `locales` (enabled locales), `b2b` (enabled, requireApproval, showPricesToGuests),
`samples` (cartSampleEnabled, maxPerOrder, requestFormEnabled), `newsletter`, `whatsapp`.
`getSettings(key)` returns the parsed value merged over defaults (cached, tag `TAGS.settings`).
Money values are integer kuruş everywhere (`12990` = 129,90 ₺).

### Theme engine — `src/lib/theme`
- `engine.ts`: `buildPalette(hex): Record<50|100|...|950, string>` (OKLCH via culori);
  `contrastText(hex): "#ffffff" | <dark>` (WCAG AA); `buildThemeCss(tokens: ThemeTokens): string`
  producing variables for `:root` and `.dark`; `productScopeStyle(accentHex): CSSProperties` that sets
  the `--product*` variables for a subtree (per-product theming).
- CSS variables (consumed by Tailwind via `@theme inline` in `globals.css`):
  `--bg --surface --surface-2 --text --text-muted --border --ring`
  `--brand-50 … --brand-950 --brand --brand-contrast` (navy, from logo #03265F)
  `--gold-50 … --gold-950 --gold --gold-contrast` (from logo #DDA82A)
  `--product --product-soft --product-strong --product-contrast` (defaults to gold; overridden per product)
  `--radius --font-heading --font-body`.
  Tailwind utilities therefore exist as `bg-bg text-text bg-brand text-gold bg-product border-border` etc.
- `getActiveTheme()`: cached (tag `TAGS.theme`, short cacheLife) — picks the highest-priority scheduled
  theme whose window contains now, else the default theme.
- `<ThemeStyle />` server component injects the generated CSS in the storefront root layout.
- Dark mode: `class="dark"` on `<html>`, chosen by the visitor (toggle) or system preference, applied
  before paint (no flash).

### Data layer — `src/lib/data`
Cached functions (tagged) returning plain serializable objects, already localized where sensible:
`getMenus()`, `getActiveAnnouncements()`, `getPage(slug)` (with visible, scheduled-active sections in
order), `listProducts(opts)`, `getProduct(slug)`, `listCategories()`, `getApprovedReviews(productId)`.
User-dependent data (cart, session, business prices) is never inside `"use cache"`; it is read in
small dynamic components wrapped in `<Suspense>`.

### Page builder — `src/components/sections`
`registry.ts` maps `type` → `{ label, schema (zod), defaults, Component }`. A section component receives
`{ content, locale, messages }`. Planned types: `hero`, `scent_showcase`, `featured_products`,
`packaging`, `lifestyle_gallery`, `b2b_cta`, `sample_cta`, `story`, `testimonials`, `newsletter`,
`rich_text`, `image_banner`, `faq`. Unknown types render nothing (never crash the page).

### Media — `src/lib/media`
`scripts/import-media.ts` converts sources to AVIF + WebP at widths 480/768/1200/1800 (never upscaled),
stores them in `public/media/<folder>/`, computes a tiny blur placeholder and dominant color, and inserts
`media` rows (`variants` lists every file). `<Img media={...} sizes="..." priority? />` renders a
`<picture>` with AVIF/WebP `srcset`, explicit width/height (no layout shift) and the blur placeholder.

### Auth & panel
Better Auth: email + password, admin plugin (roles: admin, editor, staff, customer), extra user fields
(phone, locale, companyId, customerGroupId, marketingConsent). `/panel/**` requires role admin|editor|staff:
`proxy.ts` does a fast cookie-presence redirect to `/panel/giris`; every panel page and server action
re-checks the session and role on the server (`requireStaff()` in `src/lib/session.ts`).

## Design direction (from the client's catalog)
Warm ivory background (#F9F8F5), navy text/headlines (#14284B / logo #03265F), gold accents
(#B8974F muted, logo #DDA82A), hairlines #E6E2DA, generous white space, editorial layout,
large elegant serif display headings + clean sans body, small uppercase letter-spaced gold eyebrows.
Per-product colors: Lavanta Latte #C2ADD1, Lavanta #8E61B6, Portakal #E9952E, Okyanus #329BC0.
Motion: subtle, smooth, purposeful (respect `prefers-reduced-motion`). Mobile first. Accessible (AA).
Turkish casing: always set `lang` so `uppercase` renders İ correctly.

## Quality bar
TypeScript strict, no `any` without a reason. Server Components by default; `"use client"` only for
interactivity. Validate every form/action input with zod. Never trust client prices: totals are
recomputed on the server. Keep components small and named in English; user-facing copy comes from
messages or the database.
